# Maison Aleri

Maison Aleri is an ultra-premium digital fashion house experience.

## Current build
- Cinematic luxury storefront
- Responsive editorial layout
- Interactive 3D-inspired garment hero
- Collection/product cards
- Wishlist and cart interaction foundation
- Journal/editorial section
- Mobile navigation
- POD-ready commerce architecture

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
